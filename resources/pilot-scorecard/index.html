Evaluation method

Measure reviewed outcomes, not demo polish.

Agree closure definitions, baseline files and error limits before a pilot starts. Keep the scorecard empty until the records have been reviewed.

Review the proposed pilot scopeResearch-stage concept · No autonomous fund movement
Comparable inputs

Reproduce the same 20 closes.

Use the same historical bank, GL and daily-position files as the current-tool baseline. Preserve cutoffs, missing sources and unavailable confirmations. Log exclusions with reasons and retain the original denominator.

  • One entity and explicitly stated currency
  • Exception counts and values per close
  • Baseline process and file versions recorded
Accepted closure

Require evidence and the treasurer’s decision.

Count a closure only when the evidence supports the disposition and the treasurer accepts it. Record a rejected candidate or reviewed hold separately. A candidate journal that remains unposted does not eliminate the observed bank-to-GL difference.

What to measure

Count the friction and the errors.

Track reviewer handling time and elapsed time to close as separate measures. Record feed-staleness incidents, false alarms, false closures, omissions and overrides alongside accepted outcomes. Use raw counts and denominators before percentages.

  • Treasurer-accepted exception closures
  • Resolved variance versus explained-but-unposted variance
  • Reviewer minutes and elapsed close time
  • False positives, omissions and unresolved items
Decision gate

Set the standard before seeing the result.

Agree what “outperform” means and the acceptable error limits before testing. Advance only with reproducible incremental value and treasury/security approval. A material false closure, concealed stale source, control bypass or write-capable pilot behavior requires pause and review.

Demand evidence

A click is not a purchase decision.

Separate a demo visit, qualified conversation, data-access permission, scoped proposal and signed or funded pilot. If the sample contains too few relevant exceptions, report the result as inconclusive. Visual polish does not change that decision.
